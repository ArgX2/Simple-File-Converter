# 언어 추가 및 수정

`src/translations.json`은 한국어 문구를 키로 사용하는 오프라인 번역 목록입니다. 영어 및 14개 추가 언어의 모든 키를 유지하며 한국어는 원문을 사용합니다. `{v0}`, `{v1}` 등 자리표시자는 삭제하거나 이름을 바꾸지 마세요. 파일 경로와 외부 오류 원문은 번역하지 않습니다.

새 언어를 추가하려면 `src/i18n.py`의 `LANGUAGES`에 코드와 자국어 이름을 등록하고, JSON에 영어 목록과 같은 키를 가진 번역을 추가하세요. 오른쪽에서 왼쪽으로 읽는 언어는 `set_language()`의 방향 설정에도 추가하세요.

앱은 Windows 표시 언어 목록을 순서대로 확인합니다. 중국어는 Hant/TW/HK/MO를 번체로, 나머지를 간체로 선택합니다. 지원 언어가 없으면 영어를 사용합니다. 사용자 선택은 QSettings의 사용자 범위 INI 설정에 저장하며, 탐색기 메뉴 등록 정보와 분리되어 메뉴를 해제해도 유지됩니다.

언어 변경은 목록·출력 형식·결과를 보존합니다. 변환 중에는 변경할 수 없습니다. 성공·실패 판단에는 표시 언어와 독립적인 기존 상태 값을 사용합니다. 우클릭 메뉴가 활성화되어 있으면 언어 변경 시 메뉴 문구를 다시 등록합니다.

자동 테스트는 카탈로그 누락, 자리표시자, 시스템 언어 선택, 설정 저장, 실시간 전환, 양방향 배치 및 변환 결과를 검증합니다. 자연스러운 표현과 Windows 기본 대화상자·탐색기 표시는 수동 검수 대상입니다.
