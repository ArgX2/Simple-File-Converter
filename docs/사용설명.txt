Simple File Converter
Windows 10/11 64비트용 · 버전 v1.1.0

실행 방법
Simple File Converter.exe를 실행하세요. Python이나 별도의 변환 프로그램 설치는 필요 없습니다.
압축 파일로 받았다면 전체 압축을 풀고 실행하세요.
단일 파일 포터블 버전은 Simple File Converter.exe 하나로 실행됩니다.

사용 방법
1. 파일을 창에 드래그하거나 [파일 선택]으로 추가합니다.
2. 각 파일의 [변환 형식]에서 원하는 형식을 선택합니다.
3. 저장 위치를 지정하고 [변환 시작]을 누릅니다.
   [원본 폴더에 저장]을 체크하면 각 파일이 있는 폴더에 결과를 저장합니다.
4. [저장 폴더 열기] 또는 완료된 행을 두 번 클릭해서 결과를 확인합니다.
실패한 행을 두 번 클릭하면 상세 오류가 표시됩니다.

우클릭 변환
프로그램 맨 아래의 [우클릭 변환 메뉴 사용]을 체크하면 현재 Windows 사용자에게
메뉴를 등록합니다. 체크를 해제하면 메뉴가 제거됩니다.
파일 우클릭 → Simple File Converter → 원하는 형식을 선택하세요.
Windows 11에서는 [더 많은 옵션 표시] 안에 나타납니다.
결과는 항상 원본 파일과 같은 폴더에 저장되며, 같은 이름이 있으면 번호를 붙입니다.
메뉴는 파일 확장자에 맞춰 표시하며, 선택 후 실제 파일 내용을 검사합니다.
예를 들어 음성 트랙이 없는 영상은 음성 파일로 추출할 수 없습니다.
PDF의 PPT/PPTX 변환은 이미지 슬라이드 방식입니다.
우클릭 변환은 한 번에 한 파일을 대상으로 하며, 성공/실패 알림은 2.5초 표시됩니다.
메뉴 등록 후 실행 파일을 옮기거나 삭제하지 마세요. 위치를 바꾼 경우 새 위치에서
프로그램을 실행하고 체크를 껐다 켜면 연결이 갱신됩니다.

상호작용과 알림 (1.1)
- 창 위로 파일을 드래그하면 푸른 테두리가 맥동하며 감지된 파일 수를 표시합니다.
- 우측 하단 알림: 파랑은 안내/파일 입력, 초록은 완료, 빨강은 오류입니다.
- 모든 알림은 2.5초 뒤 자동으로 사라집니다.
- × 버튼으로 닫을 수 있고, 오류 알림의 [상세 보기]에서 원인을 확인합니다.
- 버튼의 마우스 반응, 알림의 이동/투명도, 완료 표시가 부드럽게 변합니다.

주요 지원 범위
PPT/PPTX → PDF: PowerPoint 또는 LibreOffice 필요. 파일 추가 시 확인 팝업 표시.
PDF → PPTX: 페이지별 이미지 슬라이드. 별도 Office 설치 불필요.
PDF → PPT: PowerPoint 또는 LibreOffice 필요.
PDF의 텍스트/도형을 개별 편집 가능한 형태로 복원하지 않습니다.
역방향 변환 시작 시 확인 팝업 표시. 확인 팝업은 선택할 때까지 유지됩니다.
PPT 입력 또는 PPT 변환 최초 확인에서 Yes를 누르면 목록이 비워질 때까지
추가 확인을 생략합니다. 목록 비우기 또는 마지막 항목 삭제 시 초기화됩니다.
변환 성공/실패 알림은 기존처럼 2.5초 후 사라집니다.
Office 작업 취소는 문서 정리가 끝난 뒤 적용됩니다. 응답 제한은 120초입니다.
로그인 관련 오류 시 브라우저 열기 확인 팝업을 표시합니다.
확인하면 Microsoft 로그인 페이지를 엽니다. 로그인 후 변환을 다시 시도하세요.
Windows 세션/Office 앱 인증 오류는 브라우저 로그인만으로 해결되지 않을 수 있습니다.
영상 입력: MP4, AVI, MKV, MOV, WEBM, WMV, M4V, MPG, MPEG
영상 출력: MP4, AVI, MKV, MOV, WEBM, GIF, PNG, JPG
음성이 있는 영상은 MP3 등 음성 파일로도 추출할 수 있습니다.
음성 입력: MP3, WAV, FLAC, AAC, M4A, OGG, OPUS, WMA
음성 출력: MP3, WAV, FLAC, M4A, OGG, AAC, OPUS
이미지 입력: PNG, JPG, JPEG, GIF, WEBP, BMP, TIF, TIFF, ICO
이미지 출력: PNG, JPG, WEBP, BMP, TIFF, GIF, PDF
움직이는 GIF는 MP4, WEBM으로도 변환할 수 있습니다.
PDF 입력: PNG, JPG, WEBP, TIFF, PPTX, PPT, DOCX로 변환합니다.
DOCX 입력: PDF로 변환합니다. Microsoft Word 또는 LibreOffice가 필요합니다.
PDF → DOCX는 텍스트와 페이지 이미지를 복원하며, 스캔 문서 OCR은 지원하지 않습니다.

변환 방식
- 파일을 인터넷에 업로드하지 않고 PC에서 처리합니다.
- 같은 이름의 결과 파일이 있으면 (1), (2) 등을 붙여 새로 저장합니다.
- PDF의 각 페이지는 144dpi 이미지로 변환되어 별도 결과 폴더에 저장됩니다.
- 영상 → PNG/JPG는 첫 번째 영상 프레임을 저장합니다.
- 움직이는 이미지 → PNG/JPG/BMP는 첫 프레임만 저장합니다.
- 움직이는 이미지 → GIF/WEBP/TIFF는 프레임을 유지합니다.
- 여러 프레임 이미지 → PDF는 각 프레임을 별도 페이지로 저장합니다.
- 영상 → GIF는 12fps, 최대 너비 720px로 변환합니다.
- JPG/BMP/PDF 변환 시 투명 영역은 흰색으로 처리합니다.
- 취소하면 현재 작업의 임시 결과는 삭제합니다. 이미 완료된 결과는 남습니다.
- 파일 내용에 따라 변환 가능한 형식이 달라집니다. 암호화된 PDF와 손상된
  파일은 처리하지 않습니다. PDF의 텍스트 추출/OCR, 편집, 병합은 포함하지 않습니다.
- 영상의 첫 영상 트랙과 첫 음성 트랙을 사용합니다. 자막과 추가 트랙은 옮기지 않습니다.
- 완전한 보존이 어려운 변환은 프로그램에서 `XXX로 불완전 변환` 형식으로 표시합니다.
  불완전 변환은 결과 품질을 보장하지 않으며, 일부 내용·서식·배치가 누락되거나 제대로 변환되지 않을 수 있습니다.
