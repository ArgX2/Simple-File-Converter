# v1.1.0 개발 상태 기록

기록일: 2026-09-21  
상태: 개발·검수·포터블 빌드 완료, 커밋 대기

## 완료한 개발 작업

- PDF 입력에 DOCX 출력을 추가했다.
- DOCX 입력에 PDF 출력을 추가했다.
- PDF→DOCX와 DOCX→PDF를 `불완전 변환`으로 표시하도록 공통 판정을 연결했다.
- 메인 UI의 파일 선택 필터와 형식 목록에 DOCX를 추가했다.
- 탐색기 우클릭 메뉴에 PDF→DOCX와 DOCX→PDF를 추가했다.
- Word 자동화용 `src/word.ps1`과 변환 엔진 `src/document.py`를 추가했다. PDF→DOCX는 Word의 숨은 PDF 가져오기 대기를 피하기 위해 내장 텍스트·페이지 이미지 추출 경로로 확정했다.
- DOCX ZIP/XML 구조, PDF 출력, 원본 보존, 결과 충돌 이름, 취소·시간 제한 처리를 구현했다.
- 변환 품질 안내와 설치 조건 안내를 추가했다.
- 16개 UI 언어의 신규 안내 문구를 추가했다.
- DOCX 엔진·취소·손상 결과·우클릭 메뉴 관련 테스트를 추가했다.
- 버전을 `1.1.0`으로 변경했다.

## 확인된 결과

- 자동 테스트: 40개 통과.
- 기존 이미지·PDF·PPT·우클릭·UI·번역 회귀 테스트: 통과.
- PowerShell 문법 파싱: 오류 없음.
- 실제 Word 설치 상태: Word 16.0.20326.20144 감지.

## 해결하지 못한 문제

- 초기 Word PDF 가져오기는 숨은 대화상자로 시간 초과했으나 내장 경로로 해결했다.
- 실제 Word DOCX→PDF, 내장 PDF→DOCX 및 왕복 변환 검증을 통과했다.
- 포터블 EXE의 기존 자가진단, 문서 변환 진단, GUI 스모크 테스트를 통과했다.
- 실제 사용자 레지스트리에 우클릭 메뉴를 등록해 PDF의 DOCX 항목과 DOCX의 PDF 항목을 확인한 뒤 메뉴를 해제했다.
