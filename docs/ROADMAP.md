# 개선 로드맵

현재 버전에는 아직 포함되지 않은 후보 기능입니다. 구현 시에는 원본 보존, 같은 이름의 결과 자동 번호 매기기, 포터블 EXE와 우클릭 메뉴 지원을 동일하게 유지합니다.

## 우선 검토

- **Word 문서**: `DOC`, `DOCX`를 PDF로 변환하고, 가능하면 PDF·이미지 형식으로도 변환합니다.
  - Windows에서는 Microsoft Word 자동화 또는 LibreOffice를 사용할 수 있습니다.
  - Word 설치 여부, 문서 암호, 글꼴·레이아웃 차이를 오류 안내에 반영해야 합니다.
  - PDF에서 DOCX로 되돌리는 변환은 원본 편집 구조가 완전히 복원되지 않을 수 있어 별도 기능으로 검토합니다.
- **한글 문서**: `HWP`, `HWPX`를 PDF로 변환합니다.
  - 한컴오피스가 설치된 Windows 환경에서의 자동화를 우선 검토합니다.
  - 한컴오피스가 없는 PC에서도 동작하게 하려면 별도 변환 엔진이나 서버가 필요할 수 있습니다.
  - 문서 버전, 암호, 표·글꼴·개체 호환성을 먼저 확인해야 합니다.

- **PDF와 문서 형식의 양방향 변환**:
  - PDF → `HTML`: 텍스트와 이미지 중심의 웹 문서로 변환합니다. 원본의 모든 위치·글꼴·상호작용을 그대로 보장하지 않습니다.
  - PDF → `PNG`: 현재처럼 페이지별 이미지로 저장합니다. 역방향 PNG → PDF는 이미지가 들어간 PDF를 만듭니다.
  - PDF → `Markdown`: 텍스트와 제목·목록을 추출합니다. 표, 배치, 이미지 위치는 원본과 달라질 수 있습니다.
  - `HTML` → PDF: 웹 페이지를 인쇄용 PDF로 렌더링합니다. 외부 폰트·스크립트·인터넷 자료는 별도 처리가 필요합니다.
  - `Markdown` → PDF: Markdown을 HTML 또는 문서로 렌더링한 뒤 PDF로 저장합니다.
  - `HTML`/`Markdown` → `PNG`: 문서를 페이지 이미지로 렌더링하는 방향도 검토합니다.
  - 이미지 묶음 → PDF: 여러 PNG/JPG를 한 개의 다중 페이지 PDF로 합치는 기능을 검토합니다.

## 추가로 가능한 후보

| 입력 | 우선 검토 출력 | 구현 경로 |
| --- | --- | --- |
| RTF, ODT, OTT | PDF, DOCX | LibreOffice 연동 |
| XLS, XLSX, ODS, CSV | PDF, XLSX, CSV | Excel 또는 LibreOffice 연동 |
| PPT, PPTX, ODP | PDF, 이미지 | 기존 Office 연동 확장 |
| SVG | PNG, JPG, PDF | SVG 렌더러 추가 |
| TXT, HTML, Markdown | PDF, TXT, HTML | 전용 문서 렌더링 추가 |
| PDF | HTML, PNG, Markdown | PDF 텍스트·이미지 추출 및 페이지 렌더링 |
| HTML, Markdown | PDF, PNG | HTML/문서 렌더러 추가 |
| PNG, JPG, TIFF 묶음 | 다중 페이지 PDF | 이미지 순서·페이지 크기 지정 |
| ZIP, 7Z, TAR 계열 | 압축 해제 후 일괄 변환 | 압축 형식별 라이브러리 추가 |

문서 형식은 프로그램과 운영체제에 따라 결과가 달라질 수 있으므로, 기능을 추가할 때 지원 프로그램 감지, 진행 상태, 실패 원인, 샘플 파일 테스트를 함께 추가합니다.

## 변환 품질 고지

원본의 편집 구조·글꼴·배치·텍스트를 100% 보장할 수 없는 변환은 변환 형식 이름 뒤에 짧은 고지를 표시합니다.

- 예: `PDF → DOCX` → **`DOCX로 변환 (손상될 수 있음)`**
- 예: `PDF → Markdown` → **`Markdown으로 변환 (손상될 수 있음)`**
- 예: `PDF → PNG` → **`PNG로 변환`** (페이지 이미지 변환이라 별도 손상 고지 없음)
- 예: `PNG → PDF` → **`PDF로 변환`** (이미지 기반 PDF로 저장된다는 설명은 상세 안내에 표시)

문구가 길어지는 언어에서는 각 언어의 짧은 번역을 사용합니다. 파일 목록의 형식 선택 메뉴, 우클릭 메뉴, 확인 팝업, 변환 완료 안내에 같은 고지를 적용하고, 상세 안내에는 텍스트·표·레이아웃 복원에 대한 구체적인 제한을 표시합니다.
