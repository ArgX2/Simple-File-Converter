# 개선 로드맵

현재 버전에는 아직 포함되지 않은 후보 기능입니다. 구현 시에는 원본 보존, 같은 이름의 결과 자동 번호 매기기, 포터블 EXE와 우클릭 메뉴 지원을 동일하게 유지합니다.

## 우선 검토

- **Word 문서**: `DOC`, `DOCX`를 PDF로 변환하고, 가능하면 PDF·이미지 형식으로도 변환합니다.
  - Windows에서는 Microsoft Word 자동화 또는 LibreOffice를 사용할 수 있습니다.
  - Word 설치 여부, 문서 암호, 글꼴·레이아웃 차이를 오류 안내에 반영해야 합니다.
  - PDF에서 DOCX로 되돌리는 변환은 원본 편집 구조가 완전히 복원되지 않을 수 있어 별도 기능으로 검토합니다.
- **한글 문서**: `HWP`, `HWPX`를 PDF로 변환합니다.
  - 한컴오피스가 설치된 Windows 환경에서의 자동화를 우선 검토합니다.
  - 한컴오피스가 없는 PC에서도 동작하게 하려면 별도 변환 엔진이나 서버가 필요할 수 있습니다.
  - 문서 버전, 암호, 표·글꼴·개체 호환성을 먼저 확인해야 합니다.

## 추가로 가능한 후보

| 입력 | 우선 검토 출력 | 구현 경로 |
| --- | --- | --- |
| RTF, ODT, OTT | PDF, DOCX | LibreOffice 연동 |
| XLS, XLSX, ODS, CSV | PDF, XLSX, CSV | Excel 또는 LibreOffice 연동 |
| PPT, PPTX, ODP | PDF, 이미지 | 기존 Office 연동 확장 |
| SVG | PNG, JPG, PDF | SVG 렌더러 추가 |
| TXT, HTML, Markdown | PDF, TXT, HTML | 전용 문서 렌더링 추가 |
| ZIP, 7Z, TAR 계열 | 압축 해제 후 일괄 변환 | 압축 형식별 라이브러리 추가 |

문서 형식은 프로그램과 운영체제에 따라 결과가 달라질 수 있으므로, 기능을 추가할 때 지원 프로그램 감지, 진행 상태, 실패 원인, 샘플 파일 테스트를 함께 추가합니다.
